# Personal website · GitHub Pages trial

This folder is a self-contained static GitHub Pages trial. `index.html` is the entry point. The four subpages are linked from the main navigation.

The visual layout was independently implemented with inspiration from [Frud's Blog](https://www.aibrium.cn/); this is not associated with that site. Text, identity, publications, CV details, music playback, and weather are clearly marked placeholders. The photography images are the site owner's own selected assets.

## Images

The trial includes 111 thumbnails (about 7.5 MB) and 111 display-quality images (about 45.4 MB). It intentionally omits the 518 MB original photos. The Photo page's enlarged-image link opens the display-quality copy and is labeled accordingly. This also avoids unintentionally publishing the originals' possible EXIF metadata.

## Deploy

For a public GitHub repository, push the *contents of this folder* to its default branch, then set **Settings → Pages → Build and deployment → Deploy from a branch → main / (root)**. The repository's root must contain `index.html`.

Before treating the site as final, replace `YOUR NAME`, review each photo for publication, add verified CV/publications content, and configure legal music playback. Do not upload unlicensed audio files.
